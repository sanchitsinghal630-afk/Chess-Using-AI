# Grandmaster Arena

Offline chess for Android by Sanchit Singhal. Play against a built-in computer opponent (three levels) or pass-and-play with a friend. Full chess rules, no ads, no tracking, no internet permission.

The game itself is a single web page (`app/src/main/assets/index.html`) shown inside a small Android WebView wrapper (Kotlin, no third-party libraries).
